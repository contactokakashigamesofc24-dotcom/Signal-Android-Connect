# Lume

Lume is an experimental, independent Android client flavor based on the open-source Signal Android codebase. It is not an official Signal app and is not affiliated with, endorsed, or supported by Signal Messenger or Signal Technology Foundation.

This branding applies only to the Lume distribution flavor: its launcher name and launcher icon. It does not intentionally redesign the conversation interface, action buttons, or in-app function icons.
