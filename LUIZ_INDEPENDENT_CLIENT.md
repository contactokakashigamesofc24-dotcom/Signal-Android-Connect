# Lume independent Android client

Lume is an experimental independent distribution flavor based on Signal Android source code. It is not developed, endorsed, or supported by Signal Messenger or Signal Technology Foundation.

## Branding and legal links

- Launcher label: Lume.
- Launcher icon: original lantern artwork created for this flavor.
- Conversation screens, action controls, and existing app behavior are not intentionally changed by the branding work.
- The Android application ID remains `br.com.contacto.signal.connect`.
- The registration and settings Terms & Privacy entry in this flavor point to `docs/LEGAL.md`.
- The project’s preliminary privacy notice is `docs/PRIVACY.md`; it explicitly records that a full data-flow audit is pending and must be completed before a public release.

## Current development status

This is an experimental independent client flavor. The separate welcome/restore screen is only a local prototype and is not the app's launcher. Do not describe the app as connected to other services or ready for release unless real registration, linking, and send/receive flows have been tested.

The project includes upstream Signal source and retains required attribution and license notices. Review all third-party libraries, assets, API keys, and build requirements before any release or repository submission.
